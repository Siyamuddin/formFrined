# Form Friend

A phone-first checklist for one Korean visa and one immigration action. It lists the official forms, the papers to bring, and the fee. You fill in and sign the forms yourself.

This milestone is the packet wizard only. There is no form filler, no PDF output, and no Supabase connection. Nothing you tap is sent to a server.

```bash
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
```

Content lives in `lib/data`. English strings live in `lib/i18n/en.ts`. A Vietnamese catalog can be added beside it later.
